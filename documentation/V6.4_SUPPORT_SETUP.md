# XDevs Portal v6.4.1 — Brevo/Gmail Email Hotfix

Support email delivery now uses Brevo's HTTPS transactional email API instead of SMTP.

## Render variables
BREVO_API_KEY=
SUPPORT_TO_EMAIL=
SUPPORT_FROM_EMAIL=

Register SUPPORT_FROM_EMAIL as a Sender in Brevo and complete the verification email sent to that address.
For this setup, the sender can be your Gmail address; an owned domain is not required just to verify that sender address.
Create an API key in Brevo and store it as BREVO_API_KEY in Render.

SUPPORT_TO_EMAIL is the inbox receiving enquiries.
The visitor remains Reply-To, so replying to the delivered message addresses the visitor.

Remove SMTP_HOST, SMTP_PORT, SMTP_USER and SMTP_PASS from Render, then redeploy.
