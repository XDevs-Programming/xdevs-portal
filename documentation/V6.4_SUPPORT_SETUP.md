# XDevs Portal v6.4.0 — Support & Communication
Required Render environment variables:
- SUPPORT_TO_EMAIL
- SUPPORT_FROM_EMAIL
- SMTP_HOST
- SMTP_PORT=587
- SMTP_USER
- SMTP_PASS
The sender's address is used as Reply-To. Do not commit credentials.
Maintenance mode is controlled by `MAINTENANCE_MODE` in `frontend/js/config.js`.
v6.4 includes public Support/direct email, project enquiry fields, formatted email/reference, anti-spam/rate limiting, Help Centre, Services, Status, maintenance mode, error pages, support entry points, accessibility/metadata/security polish.
