# XDevs Portal v6.4.1 — Email API Hotfix

v6.4.1 replaces SMTP with the Resend HTTPS email API for compatibility with the current Render Free deployment.

## Required Render variables
RESEND_API_KEY=
SUPPORT_TO_EMAIL=
SUPPORT_FROM_EMAIL=

Create RESEND_API_KEY in Resend and store it only in Render.
SUPPORT_TO_EMAIL is the inbox receiving enquiries.
SUPPORT_FROM_EMAIL must be a sender address Resend permits; for production, use an address on a verified domain.
The visitor remains the Reply-To address.

Remove SMTP_HOST, SMTP_PORT, SMTP_USER and SMTP_PASS from Render.
