# XDevs Portal v6.5.0 — Navigation & Usability Refresh

This release intentionally focuses on information architecture and usability rather than adding workflow features.

## Navigation
- Main destinations remain prominent.
- Help, Status and Changelog are grouped into a desktop More menu where those links already existed.
- On mobile, secondary destinations remain directly visible in the existing menu.
- Current-page indication and keyboard/Escape handling added.
- Skip-to-content accessibility link added.

## Responsive usability
- Better mobile CTA stacking.
- Scrollable mobile navigation for shorter screens.
- Minimum touch-target treatment for navigation.
- Safer content/card containment on narrow displays.

## Regression policy
The v6.4.1 Brevo HTTPS support-email implementation is preserved.
No v7 commission-workflow features are included.
