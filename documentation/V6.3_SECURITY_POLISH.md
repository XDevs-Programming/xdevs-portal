# XDevs Portal v6.3.0 — Security & Landing Page Polish

## Security patches

- Added `express-rate-limit`.
- General API limiter: 300 requests / 15 minutes per client.
- OAuth/auth limiter: 40 requests / 15 minutes.
- Write-action limiter: 60 write requests / minute.
- `/api/health` and `/api/version` remain lightweight for the Smart Wake Scheduler.
- Private API responses now send `Cache-Control: no-store`.
- Reduced JSON body limit from 1 MB to 512 KB and URL-encoded body limit to 256 KB.
- Hardened Helmet response headers and API referrer policy.
- Netlify now sends a restrictive Content Security Policy.
- Bearer tokens are stored in `sessionStorage` rather than `localStorage`.
- Old XDevs auth tokens in localStorage are cleared during the v6.3 migration.
- OAuth callback code is now an external JavaScript file so inline scripts can be rejected by CSP.
- Navigation menu now has improved ARIA state, Escape-key closing and outside-click closing.

## Landing page

The homepage has been rebuilt around XDevs' actual workflow:

- premium hero and animated client-portal preview;
- portal trust/features strip;
- redesigned development services bento;
- dedicated client-portal feature section;
- four-step commission process;
- redesigned pricing;
- improved reviews and FAQ layouts;
- stronger final CTA and footer;
- responsive layouts for desktop, tablet and phone.

No fake client counts, revenue figures or performance statistics were added.

## Deploy note

Run `npm install` in the backend (or let Render's normal install step run) so the new
`express-rate-limit` dependency is installed.

No new environment variables are required.
