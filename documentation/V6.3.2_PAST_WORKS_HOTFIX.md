# XDevs Portal v6.3.2 — Past Works Hotfix

## Cause

The v6.3 security update introduced a strict Content Security Policy that rejects
inline JavaScript.

`frontend/past-works.html` still contained its entire API fetch and project
renderer inside an inline `<script>` block.

The browser therefore blocked that script before it ran, leaving the original
"Loading projects…" placeholder on screen indefinitely.

## Fix

- Moved all Past Works logic to `frontend/js/past-works.js`.
- Kept the strict CSP enabled.
- Added integration with the v6.2 Smart Wake Scheduler.
- Added HTTP response validation and clearer failure handling.
- Preserved privacy-enhanced YouTube embeds using `youtube-nocookie.com`.
- Added safe handling for thumbnail URLs.

No new environment variables or backend dependencies are required.
