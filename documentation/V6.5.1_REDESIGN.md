# XDevs Portal v6.5.1 — Landing & Navigation Redesign

This is a corrective redesign after v6.5.0 did not materially change the visible landing experience.

## Visible changes
- Primary navigation reduced to Services, Work, Support and Client Portal.
- New minimal hero with stronger visual hierarchy and fewer competing elements.
- New client-portal showcase card.
- Cleaner capability rail.
- Compact responsive mobile menu.

## Preserved
- Brevo HTTPS support-email delivery from v6.4.1.
- Existing support/help/status/services/past works/legal pages.
- Existing backend functionality.
- No v7 commission workflow features.
