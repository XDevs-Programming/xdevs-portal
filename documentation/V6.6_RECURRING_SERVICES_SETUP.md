# XDevs Portal v6.6.0 — Recurring Services

## What was added
- Admin-created monthly or yearly recurring services for maintenance, hosting and ongoing contracts.
- Client Stripe Checkout setup for the recurring payment mandate/payment method.
- Stripe subscription IDs and lifecycle status stored in MongoDB.
- Client cancellation **request** only — clients cannot execute Stripe cancellation from the portal.
- Admin controls to cancel immediately or at the end of the current billing period.
- Admin can resolve/decline a cancellation request without cancelling.
- Billing-event history for successful/failed recurring invoices.
- Client notifications for recurring payment success/failure.
- Admin notifications for cancellation requests.

## Stripe configuration
No new environment variables are required beyond the existing:
- STRIPE_SECRET_KEY
- STRIPE_WEBHOOK_SECRET

In Stripe Dashboard, enable the recurring payment methods you want Checkout to offer. For UK Direct Debit, enable Bacs Direct Debit if it is available on the Stripe account. Checkout is intentionally allowed to display Stripe's eligible enabled methods instead of hard-coding a method that may not be enabled for the account.

The existing webhook endpoint remains:
`/api/payments/webhook`

Ensure the webhook listens for:
- checkout.session.completed
- checkout.session.async_payment_succeeded
- checkout.session.async_payment_failed
- checkout.session.expired
- customer.subscription.updated
- customer.subscription.deleted
- invoice.paid
- invoice.payment_failed

## Workflow
1. Admin opens **Recurring services** and creates a service against a client/project.
2. Client opens **Recurring services** and clicks **Set up recurring payment**.
3. Stripe Checkout securely collects the eligible recurring payment method/mandate.
4. Stripe webhook activates and keeps the contract status synchronized.
5. Client may click **Request cancellation** and optionally provide a reason.
6. Admin receives the request and chooses **Cancel at period end**, **Cancel immediately**, or resolves the request without cancellation.

## Important
Stripe remains the payment-data processor. Bank/card details are not stored by XDevs Portal.
