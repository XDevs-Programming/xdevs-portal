# XDevs Portal v6.3.1 — Login CSP Hotfix

## Cause

v6.3.0 added a strict Content Security Policy containing:

`script-src 'self' https://xdevs-portal.onrender.com`

This correctly blocks inline JavaScript, but the sign-in page still contained
an inline `<script>` responsible for attaching the Discord and Google button
click handlers. The browser therefore displayed the buttons but refused to run
their JavaScript.

## Fix

- Moved all login-page JavaScript to `frontend/js/login.js`.
- Kept the strict Content Security Policy enabled.
- Did **not** add `'unsafe-inline'` to `script-src`.
- Added a visible fallback error if starting OAuth fails.

No new environment variables are required.
