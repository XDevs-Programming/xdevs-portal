# XDevs Programming Portal

A complete full-stack commission portal with:

- Public marketing website
- Discord and Google OAuth login
- Client and admin dashboards
- Commission creation and status management
- Client reviews
- MongoDB Atlas storage
- Render-ready backend
- Netlify-ready frontend

## Folder structure

```text
xdevs-complete-portal/
├── backend/
└── frontend/
```

Deploy `backend/` to Render and `frontend/` to Netlify.

Read `DEPLOYMENT.md` before publishing.
