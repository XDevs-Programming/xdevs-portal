v6.2.0 — Smart Wake Scheduler

3 September 2026
  • Added silent Render pre-warming when visitors enter the public website.
  • Added a branded XDevs startup screen when secure services are still waking.
  • OAuth sign-in now waits for backend readiness before leaving the Netlify frontend.
  • Direct dashboard visits automatically wait for the API before authenticated requests begin.
  • Socket.IO now loads dynamically after the backend is ready, reducing cold-start blocking.
  • Added configurable wake timeouts and retry intervals in the central frontend config.
